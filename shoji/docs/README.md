# Документация shoji

shoji — пакет интерфейсов для Tori: окна с панелями, кнопками, полями ввода, списками, картинками и векторным текстом. Работает в Linux и Windows из одного исходника, без GTK, Qt и других библиотек: всё рисуется программно в пиксели окна.

Начни с первой главы, остальные читаются в любом порядке.

| Глава | О чём |
| :--- | :--- |
| [1. Начало](01-start.md) | установка, первое окно, цикл кадров, как устроен immediate mode |
| [2. Раскладка](02-layout.md) | панели, колонки, ряды, отступы, своё место под виджет, адаптивная раскладка и прокрутка |
| [3. Виджеты](03-widgets.md) | кнопки, флажки, переключатели, ползунки, списки, вкладки, поля ввода, текст |
| [4. Текст, шрифты и языки](04-text.md) | свои шрифты, запасные и системные шрифты, ввод на любом языке, ограничения |
| [5. Картинки](05-images.md) | PNG, картинки в раскладке, кнопки-картинки, картинки в произвольном месте |
| [6. Масштаб](06-scale.md) | логические пиксели, DPI экрана, зум пользователя |
| [7. Темы](07-themes.md) | тёмная и светлая темы, акцент, свои цвета и размеры |
| [8. Рисование](08-drawing.md) | прямоугольники, текст и картинки где угодно, холст и модуль `draw` |
| [Справочник](09-reference.md) | все функции и поля одним списком |
