# tori-index

Индекс пакетов для [Tori](https://github.com/torilang). Отсюда их берёт пакетный менеджер `nest`:

```bash
nest install math
```

## Как устроен

Одна папка — один пакет, имя папки — имя пакета (латиница, цифры и `_`, не с цифры). В папке:

* `pack.toml` — кто и что:

  ```toml
  [package]
  name = "math"
  author = "ник автора"
  version = "0.1.0"
  description = "что делает"
  license = "MIT"
  ```

* код пакета: `lib.tr` (это `use имя`) и другие модули (`use имя/модуль`), в корне папки или в `src/`;
* `nest.toml` с `[deps]`, если пакет зависит от других.

Если код живёт в своём репозитории, в папке лежит только `pack.toml` со строкой `git = "https://github.com/…"`.

## Как добавить пакет

Форкни репозиторий, добавь папку пакета и открой pull request.
